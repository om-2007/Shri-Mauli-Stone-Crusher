# Shri Mauli Stone Crusher

Billing and management app for Shri Mauli Stone Crusher.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set `DATABASE_URL` and `CRYPTO_SECRET` in `.env.local`.
3. Run the app:
   `npm run dev`
